Overview

Features

PriceFM and PriceFM+ both produce day-ahead price trajectories with uncertainty. PriceFM+ adds cross-border flow information and adapts the fusion of input features through looped cross-attention.

FeaturePriceFMPriceFM+
InputPrice, renewable generation and loadPrice, renewable generation, load and cross-border power flows (imports and exports)
OutputPrice trajectory with uncertaintyPrice trajectory with uncertainty
AdaptivenessTune each graph cutoff per regionSelf-adapted through looped cross-attention

Results

Testing performance across 40 European regions and the three feature cases. Scores average over observed price slots and 273 test days across three folds. All values are in EUR/MWh and lower is better. The lowest value in each column is bold, and the second-lowest is underlined. Statistical significance is assessed with the two-sided Diebold–Mariano test on paired daily losses.
